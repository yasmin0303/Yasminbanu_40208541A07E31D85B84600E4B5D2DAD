# 🎵 Song Playlist Web App

This project was developed as part of the **Naan Mudhalvan Program** at our college.

## 🧑‍💻 Role: Team Lead

I led a team of 4 members, managed the project workflow, and contributed to the design and development of the application.

---

## 📌 Project Overview

The **Song Playlist App** allows users to:
- 🎧 Add songs to a playlist
- 🔍 Search for songs
- ❤️ Mark favorites
- 🗑️ Remove songs from the list

The goal was to create a simple, user-friendly interface for managing a personal playlist.

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

---

## 🚀 Features
- Responsive UI
- Easy-to-use buttons for controlling playlist
- Local storage to save data temporarily
